# VisualPuzzles

**Data.** [neulab/VisualPuzzles](https://huggingface.co/datasets/neulab/VisualPuzzles) at revision `e6bc28fb`, the released (train) split, 1,168 questions.

**Scoring.** Option letter, extracted as for BLINK, exact match.

The prompt is in `prompt.md`; settings per model are in `models.yaml`.
