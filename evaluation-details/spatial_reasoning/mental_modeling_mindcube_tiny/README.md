# MindCube-Tiny

**Data.** [MLL-Lab/MindCube](https://huggingface.co/datasets/MLL-Lab/MindCube) at revision `9c941b46`, the official tiny benchmark (`MindCube_tinybench.jsonl`), 1,050 questions (among 600, around 250, rotation 200).

**Scoring.** The official MindCube answer parser is applied to the final reply; exact letter match.

The prompt is in `prompt.md`; settings per model are in `models.yaml`.
