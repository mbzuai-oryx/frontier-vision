# V*Bench

**Data.** [craigwu/vstar_bench](https://huggingface.co/datasets/craigwu/vstar_bench) at revision `d9ae62c9`, test split, 191 questions. Images are sent at full resolution.

**Scoring.** Option letter A–D, extracted as for BLINK, exact match.

The prompt is in `prompt.md`; settings per model are in `models.yaml`.
